## Overview
A saved view stores the current filters, columns, sort and view settings under a name, so you can reopen the same list in one click.

## Before you start
- Any member can save private views. Sharing a view with everyone or with teams needs the views.share permission (Owner, Admin, Sales Manager).

## Steps
1. Click **Contacts** in the left sidebar, then **People (Contacts)**.
2. Click the **Individuals** tab.
3. Set up the list the way you want: filters, sort, columns and view mode.
4. Click **Saved views**.
5. Click **Save as new view…**.
6. Enter a **Name**.
7. Optionally, in **Who can use it**, choose **Only me**, **Everyone** or **Selected teams**.
8. Optionally switch on **Open with this view by default**.
9. Click **Save view**.

## Result
The view's name replaces "Saved views" on the button, and it is listed in the **Saved views** menu.

## Tips
- To update a view you own, open it, change the list, then choose **Save changes to "view name"** in the menu.
- Use **Delete view** in the same menu to remove a view you own.
- Shared views show a **Shared** badge. The Companies page does not have saved views.
