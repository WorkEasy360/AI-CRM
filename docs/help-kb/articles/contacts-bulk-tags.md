## Overview
Apply one tag to, or remove one tag from, a group of selected contacts or companies in a single step.

## Before you start
- You need bulk update permission (Owner, Admin, Sales Manager).
- The tag must already exist in your workspace.

## Steps
1. Click **Contacts** in the left sidebar, then **People (Contacts)**.
2. Click the **Individuals** tab.
3. Tick the checkboxes of the contacts you want.
4. In the selection bar, click **Add tag**.
5. Click the tag you want to apply.

## Result
A message such as "12 of 12 updated" appears and the tag shows on each selected contact.

## Tips
- To take a tag off, select the rows, click **Remove tag** and choose the tag.
- The same buttons appear when you select rows on the **Companies** list.
- Filter the list first (for example by Status) so that selecting all picks only the records you want.

## Troubleshooting
- **"No tags defined yet."** Tags are created in Settings → CRM Configuration → Tags. Ask an Admin if you cannot create them.
