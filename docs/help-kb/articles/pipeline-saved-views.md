## Overview
A saved view stores the current filters, columns, sort and view settings under a name, so you can reopen them in one click. You can keep it private or share it.

## Before you start
- Anyone can save private views. Sharing with others needs `views.share` (Owner, Admin or Sales Manager).

## Steps
1. Click **Pipeline** in the left sidebar.
2. Set up the filters, sort and view (Kanban, List, Sheet and so on) you want.
3. Click **Filters**, then click **Saved views**.
4. Click **Save as new view…**.
5. Type a **Name**.
6. If shown, choose **Who can use it**: **Only me**, **Everyone** or **Selected teams** (then tick the teams).
7. Optionally turn on **Open with this view by default**.
8. Click **Save view**.

## Result
"Saved" followed by the view name appears, and the **Saved views** button now shows the view's name. The view is listed in the **Saved views** menu.

## Tips
- To update a view you own, change the filters, open **Saved views** and click **Save changes to** the view.
- Use **Delete view** in the same menu to remove a view you own.
- **Stop opening with this view** removes it as your default.

## Troubleshooting
- **"Some of this view's fields are not available to you."** The view uses fields your role cannot see; those parts are left out.
