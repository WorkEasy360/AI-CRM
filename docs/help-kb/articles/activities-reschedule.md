## Overview
Rescheduling moves an activity to a new date or time. It uses the same edit form as **Edit**, so linked records, notes and attendees stay as they are.

## Before you start
- You need `activities.update` for the activity. A Sales Representative can reschedule their own activities; Owner, Admin and Sales Manager can reschedule anyone's.

## Steps
1. Click **Activities** in the left sidebar.
2. Find the activity in the table.
3. Click the **⋮** actions button at the end of its row.
4. Click **Reschedule**.
5. Change the date and time:
   - Task: **Due date** and **Time**.
   - Call: **When**.
   - Meeting: **Starts** and **Ends** (or **Date** for an all-day meeting).
6. Click **Save changes**.

## Result
An "updated" message appears. The new date shows in the **Due Date & Time** column and on the **Calendar**. A meeting reminder moves with the new start time.

## Tips
- Rescheduling an overdue task to a future date removes it from the **Overdue** card.
- On the **Calendar** tab, click an event to open the same edit form.
- For a repeating meeting, changes apply to the whole series.

## Troubleshooting
- **"This activity was changed by someone else"** Click **Reload** in the form to load the latest version, then make your change again.
