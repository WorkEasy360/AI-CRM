### Not in product
- "Other" activity kind: only Task, Call and Meeting exist.
- Follow-up as an activity kind: it is a filter tab only.
- Reminders on tasks and calls: the form offers Reminder for meetings only.
- Repeating calls: calls cannot repeat.
- Bulk actions from the table view or the Follow-ups tab: bulk selection exists only in the grouped list (All, Tasks, Calls, Meetings).
- Sending or replying to WhatsApp/email from the Activities WhatsApp/Emails tabs: those tabs are read-only logs; sending happens on the contact (or deal) page.
- Logging a past meeting from the Activities page: the "More ways to add" menu has Log a call only.

### Not in product
- Setting or changing a ticket's Product in the UI: Product is shown in Ticket Details only when already set (outside the UI) and can be used as a list filter, but neither the create dialog nor the panel lets you pick one.
- Manually setting status to In Progress: it is set automatically by the first reply on an Open ticket; there is no control for it.
- Choosing an assignee in the Create Ticket dialog: new tickets are assigned to the creator; reassign afterwards.
- Per-category SLA or business-hours SLA: SLA is hours per priority only.

### Not in product
- Permanent delete of a contact or company: the UI and API only archive (soft delete) and restore.
- Export from the Contacts or Companies list: no export button on these pages (exports live in Settings → Import & Export Data).
- Import inside the contacts list: the Add Contact → Import item only links to Settings → Import & Export Data (/settings/data).
- Favourite toggle on the contact or company detail page and on the Companies list row menu: favourites are set only from the All Contacts / Favorites / Tags list (and the Individuals row menu).
- Saved views, view modes (Kanban/Sheet/Calendar/Chart) and column picker on the Companies page: only on the Individuals tab.
- Bulk actions on the All Contacts tab: only on Individuals (List view) and Companies.
- Files tab and Tickets tab on company pages: contact pages only.
- Email quick action on company pages: only the Emails tab (New email).
- Merge duplicates: duplicates are only flagged, never merged.

- Permanent (hard) delete of pipelines, stages or deals: everything is archived.
- Restore button on a deleted deal page: gated on a `deals.restore` permission that does not exist in the catalogue (backend restore uses `deals.delete`), so it never shows.
- Opening the deal page on the Products tab from the "Add a product" link: the link adds `?tab=products` but the deal page always opens on Overview.

- Published browser-support list (none in the code).

### Not in product
- Reordering custom fields: the Custom Fields page shows a read-only Position column; there is no drag or move control and no reorder API.
- Permanently deleting a custom field: only Archive / Restore exist.
- Editing a WhatsApp template after adding it: only Add and Remove exist (no update endpoint).
- Submitting or approving WhatsApp templates from the CRM: approval happens in Meta Business Manager; the CRM only records approved templates.
- Changing AI models or per-member / per-workspace AI limits in the app: shown read-only, set in server settings.
- Applying list filters to exports: exports always contain all records in scope.
- Importing legacy .xls files or multiple worksheets: only .csv and the first sheet of .xlsx.
- Rolling back another member's import: only the member who started it can roll it back.
- Automation triggers beyond the five listed (no time-based or field-change triggers) and actions beyond task, notify owner, notify team and WhatsApp template (no email action).
- Editing an API key's permissions or expiry after creation: revoke and create a new one.
- Editing a webhook's URL or events after creation: no edit action in the UI (only test, pause/resume, rotate secret, view deliveries, delete).
